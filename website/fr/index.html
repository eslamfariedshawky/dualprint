Questions fréquentes

DualPrint est-il gratuit ?

Oui. Gratuit et open source (licence MIT).

Comment imprimer sur deux imprimantes en même temps ?

Créez une imprimante multiple dans DualPrint, sélectionnez les deux imprimantes, puis imprimez sur la nouvelle depuis n’importe quel logiciel.

Peut-il imprimer et enregistrer un PDF en même temps ?

Oui. Ajoutez « Microsoft Print to PDF » et choisissez un dossier : le PDF y est enregistré sans question.

Windows affiche « Windows protected your PC ». Est-ce sûr ?

Le fichier n’est pas encore signé numériquement, d’où l’avertissement SmartScreen. Cliquez « More info » → « Run anyway ». Le code source est public sur GitHub.
