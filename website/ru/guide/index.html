Как печатать на два принтера одновременно в Windows

Windows отправляет каждое задание только на один принтер. Ниже показано, как за минуту настроить печать одного документа сразу на два и более принтера с автоматическим сохранением PDF.

Скачать для Windows

Почему Windows не умеет этого по умолчанию

При нажатии «Печать» Windows передаёт задание ровно одному принтеру. Встроенной настройки для дублирования нет.

Часто советуют «пул принтеров» в свойствах принтера, но он отправляет задание на первый свободный принтер, а не на все сразу.

Можно печатать документ дважды, но это медленно и легко забыть — особенно со счетами, где нужны бумажная копия и PDF в архиве.

Печать на несколько принтеров с DualPrint

  1. Скачайте DualPrint

    Скачайте бесплатную программу для Windows 10 или 11, распакуйте и запустите DualPrint.exe. Один раз подтвердите запрос администратора.

  2. Добавьте мультипринтер

    Нажмите «Добавить принтер» и задайте имя, например «Счета».

  3. Выберите принтеры

    Отметьте два или более принтера. Добавьте «Microsoft Print to PDF», если нужна копия PDF.

  4. Укажите папку для PDF

    Если выбран PDF, укажите папку и при желании префикс имени файла — файлы будут сохраняться туда автоматически.

  5. Печатайте из любой программы

    В Word, Excel, браузере или учётной программе выберите новый принтер по имени.

  6. Проверьте историю

    Каждый документ появляется в истории печати с результатом по каждому принтеру.

Печать и сохранение в PDF одновременно

Выберите обычный принтер и «Microsoft Print to PDF». Вы получите бумажную копию и PDF с именем вроде Счёт_2026-11-02_15-45-00.pdf в выбранной папке без окна «Сохранить как».

Частые вопросы

Можно ли печатать на два принтера в Windows без дополнительных программ?

Нет. Windows отправляет задание на один принтер, а пул принтеров лишь распределяет задания, но не печатает на всех.

Работает ли с сетевыми и USB-принтерами?

Да. Подходит любой принтер, установленный в Windows, включая сетевые, USB и чековые принтеры.

Можно ли задать формат бумаги?

У каждого мультипринтера есть настройка формата (A4, A3, A5, Letter, Legal или автоматически). Остальные параметры берутся из настроек принтера.

Это бесплатно?

Да. DualPrint бесплатный, с открытым исходным кодом (лицензия MIT).
