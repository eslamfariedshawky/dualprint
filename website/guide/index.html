How to print to two printers at the same time in Windows

Windows sends every print job to one printer only. Here is how to print the same document on two or more printers at once, and keep an automatic PDF copy, in about a minute.

Download for Windows

Why Windows can't do it by default

When you press Print, Windows hands the job to exactly one printer. There is no built-in setting to duplicate it.

“Printer pooling” in Printer properties is often suggested, but it does something else: it sends each job to the first free printer in the pool, so every page is printed once, not on every printer.

Printing the document twice works, but it is slow and easy to forget, especially for invoices that need a paper copy and an archived PDF.

Print to multiple printers with DualPrint

  1. Download DualPrint

    Download the free app for Windows 10 or 11, unzip it and run DualPrint.exe. Approve the administrator prompt once.

  2. Add a multi printer

    Click Add printer and give it a name, for example “Invoices”.

  3. Choose the printers

    Tick two or more printers. Add “Microsoft Print to PDF” if you also want a PDF copy.

  4. Pick the PDF folder

    If PDF is selected, choose a folder and an optional file name prefix. Files are saved there automatically.

  5. Print from any app

    In Word, Excel, your browser or accounting software, choose the new printer by name and print.

  6. Check the history

    Each document appears in the print history with every destination and its result.

Print and save as PDF at the same time

Select one real printer plus “Microsoft Print to PDF”. You get the paper copy and a PDF named like Invoice_2026-11-02_15-45-00.pdf in the folder you chose, without a Save As window.

Frequently asked questions

Can Windows print to two printers at once without extra software?

No. Windows sends a job to one printer. Printer pooling only spreads jobs across printers; it does not print on all of them.

Does it work with network and USB printers?

Yes. Any printer installed in Windows can be used, including network, USB and receipt printers.

Can I use different paper sizes?

Each multi printer has a paper size setting (A4, A3, A5, Letter, Legal or automatic). Other settings use each printer's defaults.

Is it free?

Yes. DualPrint is free and open source under the MIT license.
