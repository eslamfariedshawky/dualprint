Frequently asked questions

Is DualPrint free?

Yes. It is free and open source under the MIT license.

How do I print to two printers at the same time?

Create a multi printer in DualPrint, select both printers, then print to the new printer from any app. The job is sent to both.

Can it print and save a PDF at the same time?

Yes. Select “Microsoft Print to PDF” as one of the printers and choose a folder. The PDF is saved there automatically without asking.

Windows says “Windows protected your PC”. Is it safe?

The file is not code-signed yet, so SmartScreen shows a warning. Click “More info” → “Run anyway”. The full source code is public on GitHub.
