Häufige Fragen

Ist DualPrint kostenlos?

Ja. Kostenlos und Open Source unter der MIT-Lizenz.

Wie drucke ich gleichzeitig auf zwei Druckern?

Legen Sie in DualPrint einen Mehrfachdrucker an, wählen Sie beide Drucker und drucken Sie aus jeder Anwendung auf den neuen Drucker.

Kann ich gleichzeitig drucken und als PDF speichern?

Ja. Wählen Sie „Microsoft Print to PDF“ als einen der Drucker und legen Sie einen Ordner fest – das PDF wird dort ohne Nachfrage gespeichert.

Windows zeigt „Windows protected your PC“. Ist das sicher?

Die Datei ist noch nicht digital signiert, daher zeigt SmartScreen eine Warnung. Klicken Sie auf „More info“ → „Run anyway“. Der Quellcode ist öffentlich auf GitHub verfügbar.

Einmal drucken. Überall.

Laden Sie DualPrint herunter und legen Sie Ihren ersten Mehrfachdrucker in unter einer Minute an.
