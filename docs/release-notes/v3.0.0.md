# DualPrint 3.0.0

MultiPrint is now DualPrint; your existing printers and history are kept, and pinned `MultiPrint.exe` shortcuts should be unpinned and re-pinned to `C:\DualPrint\DualPrint.exe`.

DualPrint still supports two or more printers. Download `DualPrint.zip` and run `DualPrint.exe` as administrator once. Close the old app first; do not use **Remove all** to upgrade.

- Settings, language, printer names, destinations, paper sizes, PDF prefixes, saved PDF folders and history remain in `C:\DualPrint`.
- New PDF printers default to `Documents\DualPrint PDFs`. Existing PDF destinations, including `Documents\MultiPrint PDFs`, are retained; blank legacy PDF destinations keep the old default. Existing PDF files are not moved.
- **DualPrint Service** replaces `MultiPrint Watcher` and the original `DualPrint Watcher`. The new watcher waits for both legacy locks before processing jobs and publishing readiness. Its logon and one-minute repeat triggers restore the service.
- After readiness is confirmed, the old installed exe is preserved as `MultiPrint.exe.old` or `.old.<guid>` for rollback. A failed start leaves it available for retry.
- `MultiPrint.zip` remains a byte-identical compatibility download on this and every future release. Both archives contain only `DualPrint.exe`; `SHA256SUMS.txt` lists matching hashes under both filenames.

Check one test print and its history entry before resuming normal work. See [upgrade instructions](../USER_GUIDE.md#upgrading-from-multiprint-or-dualprint-1x), [duplicate-print troubleshooting and rollback](../TROUBLESHOOTING.md), and [validation limits](../qa/T012-upgrade-validation.md#remaining-checks-and-practical-limits).
